Orchestrate a Machine Learning Workflow using Amazon SageMaker Pipelines and SageMaker Model Registry
SPL-TF-300-MLMLMR-1 - Version 1.0.3

Lab overview
AnyCompany Consulting has asked you to deploy a model that analyzes potential customer churn. To scale your model, use Amazon SageMaker Pipelines and the SageMaker model registry with Amazon SageMaker Studio.

SageMaker Pipelines is a workflow orchestration tool that takes advantage of direct integration with SageMaker to improve operational resilience and reproducibility. SageMaker Studio has support for managing SageMaker Pipelines directly. Therefore, you can visualize and make changes to the pipeline runs within the same console.

In this lab, you manage different steps of an automated machine learning (ML) workflow. This includes data loading, data transformation, training and tuning, model evaluation, bias detection, and deployment. You also use the model registry for storing the trained models.

This lab uses the Customer Retention Retail dataset, available at Kaggle Customer Retention Retail. This dataset contains data about a store’s customers, such as their orders, quantity ordered, order frequency, and city. This dataset can be used to evaluate customer behavior and the likelihood of retaining a customer based on various marketing strategies.

Objectives
After completing this lab, you will be able to do the following:

Create a SageMaker pipeline.
View pipeline steps and artifacts.
Register trained models with the model registry through a pipeline step.

Lab environment
In this lab, the necessary data and a Jupyter Notebook (.ipynb) file have been pre-loaded into an Amazon S3 bucket. An Amazon SageMaker Studio instance, which provides you with a fully managed Jupyter Notebook environment, has been created and granted access to the S3 bucket. This setup allows you to seamlessly work with the provided data and notebook within the SageMaker Studio environment.

Task 2: Create and monitor a SageMaker pipeline
In this task, you create and run a SageMaker pipeline, monitor the pipeline’s progress, and locate and explore some of the artifacts that are used by, or generated by, the machine learning process.

In the left navigation pane, open the lab_MLMLMR.ipynb notebook.

In the top-right corner of the notebook page, ensure that Python 3 (ipykernel) is displayed as the selected kernel to run the notebook. If a different kernel is selected, then choose the displayed kernel and then select Python 3 (ipykernel) from the Select Kernel menu.

Carefully advance through the lab_MLMLMR.ipynb notebook. Run each code cell and view its output. To run a cell, select within the cell and press Shift + Enter or, at the top of the page, choose the Run button.

When you have finished running the notebook, return here to end the lab.
